# Data Validation & Verification
This folder contains SQL queries used to ensure the accuracy, consistency and integrity of the imported datasets.

## Data Validation
Checks whether the data follows predefined rules and constraints.

- Date validation
- Price and quantity validation
- Foreign key reference validation
- Data integrity checks

## Data Verification
Confirms that the imported data matches the expected records and relationships.

- Record count verification
- Imported data verification
- Table relationship verification
- Referential integrity verification
