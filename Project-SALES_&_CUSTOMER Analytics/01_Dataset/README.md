# Project Dataset
This folder contains synthetic datasets and Python data generation scripts developed for the **SAP HANA Sales & Customer Analytics** project.
The datasets simulate a realistic retail business environment involving customers, products, sales transactions and individual sales items.

## Dataset Files

| File Name | Description |
|---|---|
| customer_data.csv | Customer information and regional details |
| product_data.csv | Product information, pricing, categories and stock quantities |
| sales_data.csv | Sales transactions, purchase dates, payment methods and order statuses |
| sales_items_data.csv | Individual sales items, quantities, unit prices and discounts |

## Python Data Generation Scripts

| File Name | Description |
|---|---|
| Customers_Data.py | Generates synthetic customer records |
| Products_Data.py | Generates synthetic product records |
| Sales_Data.py | Generates sales transactions |
| Sales_Items_Data.py | Generates individual sales item records |
