#  My SAP HANA Learning Journey 🚀

This repository documents my hands-on learning journey in **SAP HANA**, covering database fundamentals, SQL, SQLScript, and data modelling concepts.

Throughout this journey, I have practised writing SQL queries, creating and managing database tables, working with joins, functions, subqueries, and set operators, along with implementing advanced SQLScript concepts.

### 📚 Topics Covered

- Database Fundamentals
- SQL Basics and Advanced Queries
- SQL Functions, Subqueries & Set Operators
- Joins and Views
- Table Creation and Alterations
- SQLScript and Scalar User-Defined Functions
- Exception Handling and Conditional Statements
- Loops and Control Flow
- Table Functions
- Stored Procedures
- Transaction Applications
- Data Generator Applications
- Scripted Calculation Views
- Core Data Services (CDS)
- Data Warehousing Concepts

### 🎯 Objective

To strengthen my practical knowledge of SAP HANA, understand database development and analytical modelling, and apply these concepts to real-world business scenarios.

### 🛠️ What's Next?

Applying these concepts to build **SAP HANA Sales & Customer Analytics**, a hands-on project focused on sales analysis, customer insights, data modelling, and analytical reporting.

This repository will continue to evolve as I explore and implement more SAP HANA concepts.

**Learning by doing. Building by practising. Growing with SAP HANA!** 💻🔥
